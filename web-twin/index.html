For local dev, run `uvicorn robot.server:app --host 0.0.0.0` on your Mac and point this at its LAN address instead, e.g. http://192.168.1.42:8000.
Cloud endpoint settings
Used by "Find the bag in a photo," Vision Autopilot, and "Guide me to..." on the other tabs.
Enter the base URL only -- e.g. http://localhost:8080 or the NLB DNS name from the cloudformation/service.yaml stack output. Don't include a route like /analyze, /navigate, or /guidance -- each feature appends its own automatically (though pasting one of those in by mistake is harmless, it gets stripped back off). The secret field is remembered in this browser (see "Cloud endpoint settings" secret prefill in the script) -- the URL field is not, re-enter it after reloading. The secret is the vision-picar-app-shared-secret value in Secrets Manager.
