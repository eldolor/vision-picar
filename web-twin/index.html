Setting this up
When this page is served by the robot server itself, the URL above is already filled in to match — add the shared secret if the deployment requires one and tap Connect. For local development run uvicorn robot.server:app --host 0.0.0.0 and point this at that machine’s LAN address instead, e.g. http://192.168.1.42:8000. Both fields are remembered on this device, and the connection is re-established automatically next time you open the app.
Cloud endpoint settings
Powers Guide, Vision Autopilot, and photo analysis.
What goes in these fields
Enter the base URL only — e.g. http://localhost:8080, or the DNS name from the cloudformation/service.yaml stack output. Leave off any route like /analyze or /guidance; each feature appends its own (pasting one in anyway is harmless, it gets stripped). The secret is the vision-picar-app-shared-secret value in Secrets Manager. Both fields are remembered on this device.
