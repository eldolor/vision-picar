Guide me to... · AR camera guidance
Uses your phone's real camera (not the sim) -- points an arrow, then an outline once found, toward a named object using a live Claude Vision call every couple seconds against the vision service's /guidance route. Opens fullscreen and works in both portrait and landscape. Vibrates on Android; plays directional audio cues everywhere (including iOS, which doesn't support web vibration at all -- see web-twin/README.md). Requires this page to be loaded over https:// or localhost (browsers block camera access otherwise). Each tick is a real paid API call -- watch the call counter.

Cloud endpoint settings
Used by "Find the bag in a photo," Vision Autopilot, and "Guide me to..." on the other tabs.
Enter the base URL only -- e.g. http://localhost:8080 or the NLB DNS name from the cloudformation/service.yaml stack output. Don't include a route like /analyze, /navigate, or /guidance -- each feature appends its own automatically (though pasting one of those in by mistake is harmless, it gets stripped back off). Not saved between sessions (no localStorage in this preview) -- re-enter after reloading. The secret is the vision-picar-app-shared-secret value in Secrets Manager.
