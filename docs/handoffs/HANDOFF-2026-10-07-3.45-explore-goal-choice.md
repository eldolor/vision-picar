## 4. Traps met

- Editing `brain/` in the worktree a live batch runs from changes the code
  of its later runs: each stack starts a fresh brain. Prototype in a
  separate worktree until the batch's last brain has started.
- zsh does not word-split `$D`; use `${=D}`.
- `pgrep -f` in a wait loop matches the loop itself (3.44's trap, met
  again). Wait on an output file or a PID.
