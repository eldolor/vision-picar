# Handoff 2026-10-16: 3.86 The twin names a Stop's refusals

Section: [3.86-twin-stop-labels.md](../plans/ros-alignment/3.86-twin-stop-labels.md).

## What changed (`web-twin/app.js`, `web-twin/index.html`)

* New labels: `stopped` STOPPED, `person_stop` STOPPED BY A PERSON,
  `no_feedback` NO WHEEL FEEDBACK, `ros_unavailable` ROS DOWN; an unknown
  reason shown by its own name in words, never as VETOED (VETOED only for a
  server that sends no reason).
* `refusalKind()`: `veto` (safety veto: the alarm colour and the Safety
  line's VETOED flash), `calm` (a Stop, a person's Stop, a preemption: no
  colour), `fault` (faults, a press that never reached the robot or was
  answered an error, unknown reasons: the warning colour), `watchdog`
  (unchanged from `dev`: the alarm colour, no flash). One class map,
  `REFUSAL_KIND_CLASS`, for the action log and the brain refusal readout.
* The flash is drawn when the refusal comes back (not when the next frame
  lands, which over the tunnel could be after the flash ended) and cleared
  by one timer (`SAFETY_FLASH_MS`, monotonic clock).

## Open, for the user

* The watchdog record (robot server): names the last driver and replaces a

  from a finished mission. A follow-up section, the user's decision.
