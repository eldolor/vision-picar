  command line: a "wait for X to finish" loop never ends, and a queued R6

  it recorded; a copied hint formula drifts silently. Fixed: ask
  `SafetyController.scan_hint_m()`.

  stack; copy them per run (the run JSON's `full_log` is empty).

  3.43 / 3.44 into section files; `origin/dev` was merged in instead (the
