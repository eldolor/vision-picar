# Handoff 2026-10-15: 3.83 nav2's costmap on the twin's map

Section: [3.83](../plans/ros-alignment/3.83-costmap-overlay.md). Built in a
Claude Code cloud session, which has Docker but whose network policy denies
`packages.ros.org`, so the ROS image could not be built there.

## What is done

* Bridge `GET /nav/costmap` (nav2's global costmap, `/slam/map`'s shape,
  `age_s`); `RosWorld.get_costmap()`; robot server `GET /world/costmap`;
  the twin's "nav2 costmap" switch under a SLAM map (off by default).
* The twin now follows a SLAM map every second on the Sim tab with nobody
  driving from the page (before, the map moved only with a camera frame).
* `/world/map` encoded with `json.dumps` (191 -> 43 ms p90 on a 300 x 240
  house); the map's placement vectorised, pinned to the old loop.
* Criteria 1-3, 5, 6 met; 4 met uncached and FAILED cached (the fetch runs
  every call); 7 not run.
