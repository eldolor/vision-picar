# 3.115 DAgger on the chooser's own states

*`PLAN-ros-alignment.md` section 3.115; index: [README.md](README.md).*

**Why.** 3.111: the clones agree with the oracle on 42-45% of the oracle's
own held-out choices, but the choosers agree on only 16-20% of the choices
they meet when they drive themselves. The clone never saw those states.
3.114 then showed the label is not the lever (tie-aware labels: FAILED).
3.111's proposal (b), DAgger on the learner's own states with the current
facts, is the next one; the user's go, 2026-10-27 ("Go ahead"). 3.88.B's
DAgger used ten facts and a linear chooser and did not help (29% -> 24%);
this one uses F-pool-W32's 18 facts and network.

**The chooser.** F-pool-W32 as 3.114 (3.103.C's network and F-lean's 18
facts, 3.96's clone settings: 30 epochs, batch 256, lr 1e-3, seed 3961,
the hard label).

**DAgger.** Round 0 is 3.103.C's own W32 clone (`clone.pt`, the one
3.111 drove). Each round k = 1..5:

1. The round's learner (round k-1's clone) drives **1,000 training
   houses**, both modes (2,000 missions), greedy, every choice with two or
   more candidates logged with the oracle's costs and pick (3.111's
   `greedy_log`). The houses are drawn without replacement from 3.96's
   F-large training set (5,464 houses) by a seed per round (3115 + k).
2. Every round's choices are added to the oracle's 37,064 (3.110's sets,
   F-lean's columns), and a clone is trained **from scratch** on the
   whole set (3.96's clone, unchanged).
3. That clone drives 3.96's 100 selection houses, R and U.

The **kept round** is the one with the best mode-R selection reward,
round 0 included (3.88.B's rule).

**Stages after the rounds.**

* The kept clone drives 3.111's 200 diagnostic houses (`val` 0-99 and
  200-299), R and U, every choice logged; 3.111's rows for W32's clone
  and for W32's `best.json` (clone then PPO) are the comparisons, paired
  by house (3.111's bootstrap, 10,000 draws, seed 3115).
* If a round after 0 is kept: PPO from the kept clone, 3.96's budget
  unchanged (60 iterations, 48 houses x 8 rollouts, 4 epochs, lr 1e-3,
  selection every 10, seed 3961), best by mode-R selection; it then drives
  the 200 diagnostic houses. If round 0 is kept, DAgger did not help on the
  selection houses and PPO is not run.

**Criteria (written before any round runs; CLAUDE.md section 7):**

1. **The states are covered:** the kept clone's near agreement (pick
   within 1.0 m of the best, 3.111's measure) on **its own** diagnostic
   choices is **>= 10 points** above W32's clone's on its own (14.2%,
   3.111), so **>= 24.2%**.
2. **The clone drives better:** kept clone minus W32's clone on the 200
   diagnostic houses, mode R: 95% interval above 0.
3. **It survives PPO (the one that matters):** DAgger then PPO minus W32's
   `best.json` on the 200 diagnostic houses, mode R: 95% interval above
   0, and mode U's interval lower end above -0.05.

Reported, not judged: each round's data size, held-out agreement on the
oracle's 609 choices, selection R and U; the kept clone against W32's
`best.json` without PPO; the PPO curve.
