## Criteria (written before building; CLAUDE.md section 7)

1. **Each bug reproduced before it is fixed**: a test (a UI test in a
   real browser for the twin and the console, CLAUDE.md section 1) that
   fails on `dev` as of this reservation for the reason in the table, and
   passes with the fix. A bug that cannot be reproduced gets a written
   reason instead, and is not "fixed".
2. **No neighbour broken**: the UI test modules run in their real order,
   and the full suite through `ready --full`.
3. **Both reviewers** (`/code-review` and the Thermos bug pass): every
   change here is risky by CLAUDE.md section 6 (the guidance loop, stored
   replays and evals, paid replays). Each finding fixed or answered here.
4. **A phone-size screenshot** of each changed page state (the Settings
   note, the admin banner), CLAUDE.md section 7.
5. **Not shipped until deployed**: the twin and console are static on S3 +
   CloudFront, and the walks API is a Lambda. Deploying is asked of the
   user, not assumed; until then this section says "merged, not deployed".
