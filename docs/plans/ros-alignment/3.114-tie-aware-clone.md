# 3.114 Copy the oracle's near ties as ties

*`PLAN-ros-alignment.md` section 3.114; index: [README.md](README.md).*

**Why.** 3.111's check 3b: on **78%** of the 609 held-out oracle choices
another candidate's true path is within 1.0 m of the oracle's pick, so the
clone's label (one pick, cross-entropy) asks it to copy a near coin toss
and calls every other near-best candidate wrong. 3.111 proposed (a), a label
that scores ties as ties; the user chose it, 2026-10-27 ("Ok" to the
recommendation). Desktop only.

**The chooser.** F-pool-W32 (3.103.C: F-lean's 18 facts, one 4-head
attention layer of width 32 over the pool), the best-scoring chooser on
3.111's diagnostic houses, trained by 3.96's stages through 3.103's
`pool_run.py` patch, on the same 42-column oracle sets 3.110 used
(`goal-learn-3110/run/oracle-large`, 37,064 training choices;
`oracle-select`, 609 held out; F-lean's columns sliced from them). Only the
clone's loss changes; network, epochs (30), batch, rate, seeds and data are
3.96's.

**The labels.** Per choice, the **near set** N = the reachable candidates
whose oracle cost (true path in 0.30 m cells) is within 1.0 m of the
lowest (3.111's "near"). Choices with no reachable candidate are dropped,
as 3.96 does.

* **hard** (3.96's loss): -log p(oracle's pick).
* **soft**: cross-entropy to the uniform distribution over N,
  -(1/|N|) sum over N of log p.
* **set**: -log of the probability on N, -log sum over N of p: any
  near-best pick is right, and the network may put it all on one of them.

Each loss trains seeds 3961-3963 (9 clones; hard is retrained here so the
three losses are compared on equal footing; 3.103.C's own W32 clone is
seed 3961's hard).

**Stages.**

1. **Clones and the oracle's states:** each clone's held-out (609) exact
   agreement and near agreement (pick in N).
2. **The clones drive:** every clone greedy on 3.96's 100 selection houses,
   R and U. The loss with the higher mean selection R over its three seeds
   is the **chosen loss**; its seed with the highest selection R is the
   **chosen clone**; hard's best seed by the same rule is the **hard clone**.
   (Picking is done on the selection houses only, so the diagnostic houses
   below do not flatter it.) Both then drive 3.111's 200 diagnostic houses
   (`val` 0-99 and 200-299), R and U, every choice logged.
3. **PPO:** if the chosen loss is soft or set, PPO from the chosen clone
   with 3.96's budget unchanged (60 iterations of 48 houses x 8 rollouts,
   4 epochs, lr 1e-3, selection every 10, seed 3961), best kept by mode-R
   selection reward, as 3.103.C's W32 was. Its best then drives the 200
   diagnostic houses, against 3.111's rows for W32's `best.json` (hard
   clone then PPO), paired by house. If hard is chosen, stage 3 is not run
   (the tie label lost on the selection houses).

Paired differences use 3.111's bootstrap (10,000 draws, seed 3114),
per house, mode R unless stated.

**Criteria (written before any clone is trained; CLAUDE.md section 7):**

1. **The label is learned:** the chosen loss's mean held-out near
   agreement is **>= 5 points** above hard's, every seed above every
   hard seed.
2. **The clone drives better:** stage 2's chosen clone minus the hard
   clone on the 200 diagnostic houses, mode R: 95% interval above 0.
3. **It survives PPO (the one that matters):** stage 3's best minus W32's
   `best.json` on the 200 diagnostic houses, mode R: 95% interval above
   0, and mode U's interval lower end above -0.05 (no trade of U for R).

Reported, not judged: near agreement and mean regret on each chooser's
own diagnostic choices (3.111's check 1 table), the PPO curve.
