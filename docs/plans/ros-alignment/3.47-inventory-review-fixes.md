# 3.47 Inventory review fixes: the stop-path race, double-counted looks, mission-id collisions, a local-only mode

*`PLAN-ros-alignment.md` section 3.47; index: [README.md](README.md).*

**Why.** 3.46 (the object inventory) merged without a code review. It was
the first change reviewed under CLAUDE.md section 6's new rule (2026-10-09):
`/code-review` plus the Thermos bug pass (`docs-review/THERMOS-BUG-PASS.md`),
since it touches the mission loop and writes stored data. Both reviewers
reported the first three defects below; the Thermos pass alone reported the
other two. Each was then confirmed against the code before fixing.

1. **A stop could skip the stop command.** `_observe` changed the
   inventory on the tick thread without `MissionRunner._lock`, while
   `_finish` read it under the lock. A new landmark joins the list one line
   before its first point, so a stop landing between the two made
   `summary()` divide by zero. `_finish` called `summary()` before
   `_safe_stop()`, so the exception skipped the stop, the policy's close,
   the end line and the save. (The robot watchdog, B3.1, still stopped the
   motors after 1 s.) The same race could fail `GET /mission/inventory`.
2. **One look could count twice.** A frame whose first detection gave
   landmark A its hit, and whose second matched B and folded A into it,
   left B taking the hit again: four hits from three looks, against
   `_absorb`'s rule that a merge never raises belief by itself.
3. **Two missions in one second shared a file.** The mission id was the
   time to the second plus the target, so a quick restart overwrote the
   first mission's local file and S3 key.
4. **No local-only mode.** `service/tunnel/run.sh` used
   `${INVENTORY_BUCKET:-lookup}`, which treats `INVENTORY_BUCKET=` as unset,
   so every run with AWS credentials uploaded the list of what is in the
   house.
5. **A cut-off save left a truncated file.** The save runs on a daemon
   thread; a brain exiting mid-write left half a JSON file.

**Criteria.** One per defect: a test that reproduces it, shown red with the
fix reverted and green with it, and the 3.46 suites still green. These were
written with the fixes rather than before them; the bar is the
reproduction, not a measured threshold.

**Results (2026-10-09).** All five met.
