# 3.109 Explore's goal facts in numpy, the same answers

*`PLAN-ros-alignment.md` section 3.109; index: [README.md](README.md).*

**Why.** 3.103's board timing (2026-10-26, the full stack running: nav2,
YOLOE + CLIP, Qwen VE): every learned chooser's whole choice is 316-341 ms
p90 at 15 W against the 100 ms bar, and over half of it is 3.65's ten goal
facts, `brain/goal_policy.py` `features()`: 185 ms p90 for ~85 candidates
(27.6 ms on the desktop). For each candidate it walks a 41 x 41 square of
the 0.05 m map in two Python loops, indexing `m["cells"]` (a list) and a set
of `(x, y)` tuples. The user, 2026-10-26: "Agreed on the Numpy rewrite."

**The change (written before building).**

* `goal_context(m, seen_cells)` builds, once per choice, the map as a
  numpy array and the unseen mask; `features(..., ctx=ctx)` then counts the
  unknown, free and unseen cells of each candidate's 1 m disc with array
  operations over a precomputed disc of offsets, clipped at the map's
  edges exactly as the loops are. Integer counts and the same divisions, so
  the same floats. Without `ctx`, `features()` builds its own (one call
  alone stays correct, only slower per call).
* `brain/explore.py` builds one context per choice and passes it (two
  keyword arguments; nothing else in explore changes).
* 3.96's and 3.103's benchmark choices pass a context too, so the board
  timing measures the new path.
* Out of scope: the room cut (`segment()`, 41 ms on the board) and the map
  work (89 ms). Even with the ten facts free the whole choice stays near
  145 ms; caching the room cut per map version and trimming the map work
  are later sections.

**Criteria (written before building; CLAUDE.md section 7):**

1. **The same answers, exactly.** Today's `features()` is frozen as
   `tests/goal_features_reference.py`. On 3.96's benchmark (the six live
   0.05 m maps x 20 poses, its seed) x every candidate x two seen sets

   simulator's four houses and 20 ProcTHOR `val` houses, the new
   `features()` returns lists `==` the reference's (exact float equality,

2. **Fast on the board, under the full stack:** the ten facts' part of a

3. **The real path:** one live `home_first_floor` explore mission
   (`tests/demo_explore.py one`) under `EXPLORE_GOAL_POLICY=network`:
   `found`, 0 contact samples; `choice_ms` reported. (Amendment 1, before
   any live run: as first written this said `rule`, whose choice never
   calls `features()`; the network policy scores every candidate with it.)
4. **No new cost elsewhere:** the full suite passes; nothing new in
   `requirements.txt`.
