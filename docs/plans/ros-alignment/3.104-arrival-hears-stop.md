# 3.104 A person's Stop during the arrival's confirmation ends the mission cancelled, not found

*`PLAN-ros-alignment.md` section 3.104; index: [README.md](README.md).*

**Why.** The open item in CLAUDE.md 3b (3.80, 3.99's known limits): a
person's robot-server Stop while the brain sends no verb -- the arrival's
identity confirmation, local or cloud -- can still end the mission `found`.
The brain hears 3.84's latch only as a refused verb, and between the arrival
and `_finish(FOUND)` it sends none, so a Stop pressed while the confirmation
waits is never heard: the mission reads `found`, 3.99's line carries no
intervention, and the person's Stop is not the last word. The same holds for
a person taking over at the D-pad in that window (a preemption, heard only on
the next verb). Chosen by the user, 2026-10-26, from the open list.

**The change.** Before a completed mission is finished, the runner asks the
robot server once with 3.88's probe: `look_center()`, which moves nothing at
arrival (or only the camera) and is answered by name under the latch or a
person's hold. A person's refusal ends the mission through the existing path
(`_finish_preempted`: `cancelled`/`stop`, or `cancelled`/`dpad`); a veto, the
mission's own nav2 goal still holding (`ros is driving`, `nav2 goal is
active`), or the robot server not answering leave the found as it was
(logged). Nothing in the robot server changes.

**Criteria (written before building; CLAUDE.md section 7):**

1. A person's Stop (latched) during the arrival's confirmation, which then
   says yes, ends the mission `cancelled`, `cancelled_by: "stop"`, never
   `found`; a person's D-pad take-over in the same window ends it
   `cancelled`/`dpad`. Red on `dev` first.
2. Without a Stop the same mission still ends `found`; a veto, the
   mission's own goal holding and a robot server that does not answer the
   probe keep `found`. 3.99's line records the Stop as an intervention.
3. The fast tier passes; the existing found, Stop, intervention and sweep
   suites are unchanged (no pinned number moves).

## Results (2026-10-26, in process)

1. Met: `tests/test_arrival_hears_stop.py`. On `dev` the Stop and the
   take-over both read `found` (red for that reason); now `cancelled`/`stop`
   with a `stop`/`robot_stop` intervention line, and `cancelled`/`dpad`.
2. Met (same file): `found` without a press, and after a veto, the
   mission's own goal, an autonomous holder or a robot server that does
   not answer, each after one probe.
3. See below (the gate).

Review round 1 (`/code-review` and the Thermos pass, Sonnet): both found
that an autonomous holder's refusal at the probe turned a found into
`failed` (`_finish_preempted`'s 3.70 E5 rule), and that the probe skipped
the halt gate. Fixed, the first red-first: only a person's refusal ends it
(the latch, a manual holder, or none named); the probe goes through
`_gated`. The own-goal test is one helper, `is_own_goal_refusal()`, in
`brain/explore.py` (three copies before).

**Known limits** (recorded, not fixed):

* A D-pad take-over is heard only while the person still holds the robot
  at the probe; one whose authority lapsed during a long confirmation is
  not (the Stop latch has no lapse).
* The window is narrowed, not closed: a Stop that latches on the robot
  server after the probe's answer and before `_finish` still reads `found`
  (milliseconds).
* Only `found`/`room_reached` probe. `exhausted`, `blocked` and
  `out_of_budget` end without one; explore sends verbs every tick, so a
  latch there is normally heard on the next one.
* The probe re-centres the camera at every completed end, and the robot
  server counts a refused probe in its refusal counts. A probe past its
  2 s bound is abandoned on its thread (as 3.99's pose read) and may land
  later; 3.20 re-centres at the next start anyway.
* The stop `_finish` sends waits for the probe (at most 2 s); the
  arrival's own STOP has already been sent.
* A robot-server read of the latch (no movement) would remove the last
  three; it needs a route and a `RobotInterface` method on every backend.
