# 3.122 Room labels on the recorded walks: a first real error rate

*`PLAN-ros-alignment.md` section 3.122; index: [README.md](README.md).*

**Why.** 3.119 closed the learned goal chooser as a lever until better
facts exist, and the largest gap left is mode U (the oracle 0.773 vs W32
0.355 on the diagnostic houses): the robot does not know which room is
which. 3.116.A showed room labels in a find mission recover part of it
(paired R reward +0.091 [+0.032, +0.151] with true answers), but a 15%
wrong-answer rate left only +0.034 [-0.030, +0.097]. Whether the room
path is worth more simulator work turns on the real error rate, which is
unmeasured for `/room` (Opus 5.5): 3.70 S2b made three real calls. The
user's question (2026-10-30): does that need the Rover? Not for a first
number: the recorded rig walks are real frames of the user's house at
floor height (10-13 cm), and 3.51/3.54 already labelled their rooms by eye.

**What exists (counted 2026-10-30, before any call):**

* 15 walks with room labels (`docs/evaluations/room-labels-3.51.json`,
  `room-labels-3.54.json`), all in the recordings bucket: 1,809 frames.
* 1,462 decided frames: home gym 789 (9 walks), basement 449 (5), living
  room 154 (4), stair hall 60 (1), home office 10 (1); the rest `unsure`.
* No kitchen, bedroom, bathroom, dining room or main-floor hallway frames.
* A free, older number already recorded: `/navigate`'s `room_guess`
  (Opus 4.5) on the same frames was 77.2% right on 3.51's 224 decided
  frames and 88.4% on 3.54's 189 mapped frames: 11.6-22.8% wrong, around
  or above 3.116's 15%. `/room` is a different prompt and model.

**Cost.** `/room` costs ~$0.006-0.009 a call (3.70 S2b's three calls):
all 1,462 decided frames ~$9-13; every second decided frame in each walk
(731) ~$4.5-6.5. Calls go to Bedrock from this machine with
`AWS_PROFILE=mac-admin`, on the user's go (not given yet).

**Design (before any call).** Each decided frame through the
deployed vision service's prompt for `/room` (`vision_core.py`, Opus 5.5,
effort low, cap 256), answers mapped to the labelled room by a synonym
table written before the run (as 3.54's: `gym`, `exercise room` -> home
gym; `rec room`, `recreation room` -> basement; `foyer`, `entryway`,
`hallway` -> stair hall; `office`, `study` -> home office); an answer not
in the table, or `unclear`, counts wrong. Replies cached to disk, so a
re-run is free. Nothing written to S3; the frames are read only.

**Criteria (written before any call; CLAUDE.md section 7; fixed by amendment 1):**

1. **Frame error** over every called decided frame, with a 95% interval
   by bootstrap over walks (frames in a walk are not independent).
2. **Per-room error** for each room with >= 30 called frames (gym,
   basement, living room, stair hall).
3. **The decision it feeds** (written now): error <= 5% (3.70's 95% bar)
   -> build the simulator's noise model at the measured rate and re-run
   3.116.A's arms there; 5-15% -> first re-run 3.116.A in the simulator at
   the measured rate (free) to see whether any gain survives; > 15% ->
   the room-label path waits for the Rover's camera and viewpoints.

**Amendment 1 (the user's go, 2026-10-30, before any call).** Every
second decided frame of each walk (its 1st, 3rd, ...), plus every
stair-hall frame: 764 calls (gym 396, basement 226, living room 77, stair
hall 60, office 5), estimated $4.66-7.03, a hard stop at $8 (each call
reserves its worst case, ~$0.012, before it is sent). If the frame error
lands within 2 points of 5% or 15%, the other half may be called (the
user's go again). The prompt's list has no gym or basement, so the
synonym table is fixed here (`evaluations/room-labels-3122/score.py`
`ACCEPT`): home gym <- gym, home gym, exercise / workout / fitness / weight
room; basement <- basement, family room, rec(reation) room, game room, den,
media room, lounge, playroom, basement family / living room; living room
<- living room, family room, lounge, den, sitting room; stair hall
(labelled `hallway`) <- hallway, foyer, entryway, entry, hall, stairwell,
stairway, staircase, landing, stair hall; home office <- office, home
office, study. Judged on this table; a basement called "living room" is
reported as a lenient score, never judged. Rooms judged on their own:
>= 30 called frames (gym, basement, living room, stair hall). Bootstrap
10,000 draws over walks, seed 3122.

**Known limits.** One house, five rooms, two of them on 60 and 10 frames;
none of ProcTHOR's kitchen, bedroom or bathroom; a phone on a hand-pushed
rig, not the Rover's camera or explore's viewpoints (every 2 m and at
doorways); the reference labels were made by eye by Claude, not
adjudicated by the user.
