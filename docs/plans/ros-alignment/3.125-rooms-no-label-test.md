# 3.125 The rooms policy without room labels, on the 588 test houses

*`PLAN-ros-alignment.md` section 3.125; index: [README.md](README.md).*

**Why.** The user, 2026-10-31: "I still don't understand why we're
defaulting to rule-based. Even with the labels off, the neural net-based,
RL-based model work out better", then "go ahead, run it on the desktop ...
lock the desktop for exclusive use". 3.96's test run (588 houses,
`train` 1000-1999) judged F-large with labels and with 50% of them withheld,
never with none. A find mission has no room labels (a map carries them only
after a survey; 3.116's `find_room_labels` is off by default), so the policy
the car would run -- `explore_goal_policy: rooms` with no labels -- was only
measured on the 100 selection houses (3.96 "C wiring": R 7 goals / 23.25 m
vs the rule's 7 / 18.9; U 8 / 25.35 vs 10 / 27.6). This section runs it once
on the test houses, with the bar written first.

**What runs.** `evaluations/goal-learn-3125/run.py`, on this desktop, under
the heavy-run lock (`.git/heavy-run.lock`, PARALLEL-SESSIONS rule 7) for the
whole run. Two arms, each in target modes R and U (3.96's definitions):

* **rule**: today's default, re-run on today's `dev` (not 3.96's rows:
  3.106 changed explore since).
* **rooms**: `explore_goal_policy: rooms` exactly as the brain builds it
  (`train.py`'s `"wired"` spec, `brain/goal_policy.py` `RoomGoalPolicy`),
  no room labels.

Same houses, seeds, reward and tick cap as 3.96.C. Goals and metres are
medians over found missions. Records only: nothing in `brain/` changes.

**Criteria (written before building; CLAUDE.md section 7):** in **each**
mode R and U, `rooms` against `rule`:

1. **Finds:** `rooms` found >= 0.99 x the rule's found.
2. **Goals:** `rooms` median goals per found mission **strictly lower**
   than the rule's.
3. **Metres:** `rooms` median metres per found mission **no higher** than
   the rule's.
4. **Clean:** every `rooms` mission ends with an outcome under the tick cap
   (no `exception`, none capped).

**What the result decides.** All four met in both modes: the case for making
`rooms` the default is put to the user (the default is the user's call,
2026-10-24). Any one failed: `rule` stays, and the failure is recorded as
failed.

Information (no bar): houses each arm finds that the other does not; the
rule arm's rows against 3.96.C's recorded `rule-*.json`.
